# Hard "never claim" list (claim tier T4). One case-insensitive regex per line;
# blank lines and lines starting with # are ignored.
#
# generate_resume.py passes these to the tailoring call as off-limits, then
# FAILS the run (writes nothing) if any pattern matches the generated summary,
# bullets, or skills. Use phrases, not bare words: the profile legitimately
# mentions building a "full-stack" POC with Claude Code and lists AWS, so only
# the identity/credential/proficiency claims are blocked here.

# Credentials and certifications (none exist in the source material)
\bcertified\b
\bcertification\b
\bAWS\s+(certified|certification|solutions architect|machine learning specialty)
\b(PMP|CPA|CFA|CISSP|Six Sigma)\b
\bPh\.?D\b

# Role identities the candidate does not hold. Anchored on "a/an/as" so that
# "partnered with software engineers" is fine but "a full-stack engineer" is not.
\b(as|an?)\s+(senior\s+|lead\s+)?full[- ]?stack\s+(engineer|developer)
\b(as|an?)\s+(senior\s+|lead\s+)?software\s+(engineer|developer)
\b(as|an?)\s+(senior\s+|lead\s+)?(UX|product)\s+designer

# Tools with no source support, or proficiency levels that overclaim
\bFigma\b
\b(expert|expertise|mastery)\s+(in|with)\s+(React|JavaScript|TypeScript|AWS|Sagemaker|Kubernetes)\b
\bMLOps\s+(engineer|certification)\b
